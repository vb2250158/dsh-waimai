# 支付方式品牌图标

银行卡图标取自支付宝账号绑定列表中与同条银行卡记录对应的 `logoMini`，官方 `https://zht.alipay.com/asset/bankList.htm` 同样使用该字段。实现不维护银行名称到图标的猜测表，也不限制为当前账号的银行；任何返回受支持官方 PNG 图标的银行均可显示。未知银行、缺少图标、非允许来源、下载或解码失败使用通用银行卡图标。银行名称与四位尾号始终是选择依据，图标不参与扣款匹配。

后端仅允许 `i/gw/os/t.alipayobjects.com` 上无查询参数的 HTTPS PNG，禁止用户信息、重定向和非标准端口；无账号 Cookie、Referer 或认证头，4 秒超时，64 KiB 和 512×512 像素上限，最多四个并发请求，内存缓存最多 128 项。前端只接收内嵌 PNG，不请求外部图床。接口图片不是用户头像、卡号或绑定凭证，不写入支付偏好加密记录。

支付宝余额使用支付宝/余额宝官网公开引用的品牌 favicon：`https://i.alipayobjects.com/common/favicon/favicon.ico`。余额宝使用官方银行卡页明确标注“支付宝余额宝”的图片：`https://i.alipayobjects.com/e/201401/1qPsg8boXV.jpg`，通过 CSS 仅展示左侧品牌钱袋。两项资源内嵌在本地页面，保持原始图片字节；未宣称该历史官网资源是最新品牌规范。来源于 `https://bao.alipay.com` 的页面最终跳转 `https://yebprod.alipay.com/yeb/pcOffline.htm`。

这些品牌和图形属于对应权利人，仅用于用户识别实际支付方式；未找到单独的开源再分发许可证，不能把项目代码许可证套用于这些资源，也不据此进行公开素材发布或声称品牌背书。本次仅更新用户已授权的本机私有服务。
