# 商超加购记录

淘宝商超加购按已核验平台账号 ID 的 SHA-256 值，在本地 `retail-cart-attempts` 下保存热账本、归档和账号锁；同一账号重新登录共用记录。每次操作有唯一 `operationRef` 和单调递增 `seq`，加购结果未确认时保留 `sent` 并禁止再次加购，只有平台购物车回读精确吻合后标记为 `verified`。

读取购物车或执行加购时，在账号锁内检查整理；以记录 `createdAt` 为 activityAt，存在超过 72 小时的已确认记录时触发，将超过 24 小时的最大连续 `verified` 前缀原样写入按首尾序号命名的分卷。`sent` 永不归档。分卷和索引写入并回读校验后，才替换热账本；热账本、归档索引和每个分卷由独立代数摘要记录共同校验，进程中断后根据前后摘要以及分卷、索引和热记录的完全匹配重叠恢复；缺失或摘要不匹配时停止操作。该机制用于进程中断恢复，未执行 fsync，不保证断电后的持久性；整套账本、归档与摘要同时丢失或整体回滚时，无法仅凭同目录数据发现。全历史参与 operationRef 去重，不删除归档。

热账本最多 1000 条；若没有符合条件的可归档前缀，达到上限后停止新加购。无后台定时器、自动锁清理或归档删除；锁残留时先停止所有使用该账号的相关进程，核对记录与平台购物车，再人工处理对应锁目录。账本异常或无法确认时保持停止，勿重复操作。
