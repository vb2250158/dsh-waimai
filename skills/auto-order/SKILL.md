# 外卖任务预览

任务当前只支持时间、日期、参考菜单和预算预览。通过插件的任务页维护 `autoTasks`，每个任务具有唯一非空 `id`、名称、`platformId`、`enabled`、本地 `HH:mm` 触发时间、日期规则、自定义星期、跳过日期、菜单池、选择策略、金额上限与通知选项。平台可选 `taobao/meituan/jd`，尚未接入平台不能执行购买。

菜单池每行 `店铺 | 菜品 | 参考价格`，仅用于预览，不能据此生成接口商品或实付金额。新任务默认暂停，保留 `dryRun: true`。调用 `mcp__waimai__preview_task`（`taskId`）核对选餐、时间、平台和上限；该操作不修改执行记录、不购买。不要告诉用户关闭预览就能真实下单。

定时预览由 Host 每分钟轮询，不经过模型；同一任务每天仅触发一次，不补跑错过时间。预览触发后按通知开关记录未下单；非预览任务在触发时报告购买接口未验证并停止，不读取页面、不提交、不扣款、不推进轮换。

排查时核对启用状态、任务 ID、当前触发分钟、日期规则、跳过日期和可解析菜单，再查看本机 `notifications.jsonl` 与进程日志。既有支付占用必须保留，不能因接口迁移清零或释放未知结果。当前购买能力未验证时不要重建重复任务或反复重试。
