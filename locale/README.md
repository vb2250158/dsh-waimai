# Plugin-list translations

These files translate the plugin name and description shown in DSH. They support English (`en`), Chinese (`zh`), Japanese (`ja`), Spanish (`es`), French (`fr`), German (`de`), Russian (`ru`) and Portuguese (`pt`). Other plugin screens have their own language support.

Keep `meta.title` and `meta.description` as nonempty strings. DSH resolves them in its active language, with English as the fallback.
